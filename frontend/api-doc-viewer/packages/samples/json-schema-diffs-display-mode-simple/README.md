# JSON Schema diff fixtures — Display Mode = simple

One minimal JSON Schema document per element the `simple` display mode hides (`<case-id>/{before,after}.yaml`):
the API type's base document plus that element only. The pair replaces the element's value (one "changed" case per element). Viewer: `JsonSchemaDiffsViewer` (the pair wrapped in the OAS 3.0 template; OAS 3.1 where the case says so). Design:
[docs/design/shared/features/display-mode-annotations.md](../../../docs/design/shared/features/display-mode-annotations.md).

Generated by `node bin/generate-display-mode-simple-suites.mjs` (packages/api-doc-viewer) from
`bin/display-mode-simple-case-definitions.mjs`; the whole folder is recreated. Do not edit by hand.
