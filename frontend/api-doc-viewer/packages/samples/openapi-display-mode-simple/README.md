# OpenAPI fixtures — Display Mode = simple

One minimal OpenAPI document per element the `simple` display mode hides (`<case-id>/sample.yaml`):
the API type's base document plus that element only. Viewer: `OpenApiOperationViewer`, `POST /orders`. Design:
[docs/design/shared/features/display-mode-annotations.md](../../../docs/design/shared/features/display-mode-annotations.md).

Generated by `node bin/generate-display-mode-simple-suites.mjs` (packages/api-doc-viewer) from
`bin/display-mode-simple-case-definitions.mjs`; the whole folder is recreated. Do not edit by hand.

## Storybook and screenshot tests

Storybook: `OpenAPI Operation Suite (Display Mode = simple)`, story `Case_<case id>` (`src/stories/openapi-display-mode-simple-suite/cases.stories.tsx`;
display mode is a story control, default `detailed`). ITs: `src/it/openapi-display-mode-simple-suite/cases.it-test.ts`, every
case in display modes `detailed` and `simple` (story arg `displayMode`). These suites are the only
`simple` coverage of OpenAPI: every other suite captures `detailed` only.
