---
description: Conventions for consuming the api-processor library.
applyTo: "**/*.{ts,tsx}"
---

When writing TypeScript that imports `@netcracker/qubership-apihub-api-processor`
or `@netcracker/qubership-apihub-api-processor/processor` — running
`PackageVersionBuilder` to build/compare/export a package version, or using its
shared types, constants, and utilities — apply the `api-processor-using` skill.
