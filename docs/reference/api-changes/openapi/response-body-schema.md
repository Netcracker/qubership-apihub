# ResponseBody. Schema

## Schema

For ResponseBody schemas, changes are classified according to **Schema Changes** with **Scope Response**.

See: [Schema Changes - Scope Response](../schema-changes.md#scope-definitions)

### Example

To get specific examples for ResponseBody schemas, take the schema examples from the [Schema Changes](../schema-changes.md) section and insert them into the `responses[*].content.application/json.schema` location of an OpenAPI specification.

Example OpenAPI structure:

```yaml
paths:
  /pets:
    get:
      responses:
        '200':
          description: successful operation
          content:
            application/json:
              schema:
                # Insert schema from Schema Changes examples here
```
