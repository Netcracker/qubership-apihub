# Internal documentation

This folder holds documents for the people who build APIHUB. It is in the repository and not on the documentation site:
the site publishes the other folders of `docs/`, and this one is published on GitHub only.

## What is here

- [Team process](./process.md): work items, workflows, pull request review, and the release cadence of the team.
- Architecture decision records (ADRs): decisions that shape several modules or the repository. They will live in
  `adr/`.
- Project history: the story of the project. It is now in [`../apihub-history.md`](../apihub-history.md) and moves here
  later.
- The migration record: the final account of the move from separate repositories to this monorepo. It will live in
  `monorepo-migration/`.

## Why it is not on the site

The site is for people who install, run, use, and extend APIHUB. The material here describes how the team works and why
past decisions were made. It would add noise to the site and ties readers to internal practice. Read it on GitHub.
