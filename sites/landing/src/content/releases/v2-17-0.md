## What's New in v2.17.0

You can compare a publication with a version from another package, group DDL tables, and
see those groups in the Excel export. The dashboard shows publication errors the same way
a package does. The product Helm chart is published with the images.

### Publish against another package

- The publish dialog has a Previous version package field. It defaults to the current package
- Choose another package, and the previous-version list and the API Changes baseline come from it
- A newly published version finds its API Changes from that previous package
- Dashboard operation changes accept a reference package id

### DDL contracts

- Tables in a DDL package version can be placed in manual groups
- The Excel export of DDL entities adds a Group column
- The Excel export of DDL changes adds a summary sheet and lists each entity's changes and group

### What you see

- Dashboard publication feedback matches a package, including the publication error code
- Revision comparison keeps the requested revision when only the latest revision has errors
- An HTML export inserts template values literally, so a `$` in the specification no longer
  breaks the file
- Change-severity counters stay in a consistent order
- Change rows stretch to the full width of the API Changes view

### Install

- The Helm chart `qubership-apihub` 2.17.0 is in the registry, with the product image tags pinned
- The agent image is 2.3.0, with Helm chart `qubership-apihub-agent` 2.3.0

### Fixes

- Creating a package checks that the parent is a workspace or a group
- A changed role hierarchy can be saved
- Suspicious builds on a dashboard comparison match the versions being compared
- The count of operations with a breaking change is no longer empty when the change belongs to
  one side of the pair
