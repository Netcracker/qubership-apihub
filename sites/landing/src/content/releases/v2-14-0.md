## What's New in v2.14.0

MCP and DDL contracts move from browse-only to the same Portal workflows as REST and GraphQL: search, dashboards, changelog, and export. Database schema diffs render as tables, not just raw JSON.

### MCP and DDL advanced catalog
- Global search for MCP tools and DDL tables
- Dashboard browse, changelog, and version comparison for both contract types
- Excel export of MCP entities and DDL changes
- MCP configure/publish gates (endpoint uniqueness, artifact kind, capability warnings)
- Document `apiKind` persisted and returned by the backend

### DDL schema Diff View
- Side-by-side table schema diffs in api-doc-viewer (columns, types, constraints)
- Data-model refactor with fixture coverage for table-level changes

### Catalog and publish
- Filter a package's version list by more than one status at a time
- Previous-version status validation in the Portal matches the backend
- `xApiKind` from the build config is applied to files (no-BWC GraphQL and similar)

### Agents, ops, and security
- Run Kubernetes discovery only for specified services
- Activity history requires authorization
- Helm can mount the build-task-consumer API key as a file (`readOnlyRootFilesystem` / hardening)
- S3 cleanup job covers leftover objects

### Fixes
- Adding missing required security-scheme fields is non-breaking (OpenAPI and AsyncAPI)
- GraphQL changelog from introspection when a previous version is set
- GraphQL subscription-id / root-type name collision during changelog
- JSON Schema viewer no longer crashes on cyclic schemas with `x-` extensions
- Publication error toasts no longer show the wrong document name
- Dashboard API Changes descriptions expand correctly
