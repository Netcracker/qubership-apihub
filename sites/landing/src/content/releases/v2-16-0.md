## What's New in v2.16.0

The first product release cut from the monorepo. A draft publication continues when a document
is broken, the JSON Schema viewers are rebuilt, and DDL diffs follow foreign keys and indexes
by name. The product Helm chart is published with the images.

### Publication errors you can see

- A draft publication continues when a document fails to parse, and stores the error on the version
- The Portal shows version publication errors and a Document Errors dialog
- A failed build keeps its notifications, and you can export version notifications as an xlsx report
- The agent supports tolerant publication

### JSON Schema viewer

- `JsonSchemaViewer` and `JsonSchemaDiffsViewer` are rebuilt on the new stack
- `api-doc-viewer` 4.0.0 is a major release because of that rework

### DDL contracts

- Foreign keys and index columns are referenced by name in ddlapi, the unifier, and the diff
- A DDL compatibility suite covers those references
- Backward-compatibility status for a group of DDL packages includes contract changes
- `ddlapi` 2.0.0, `api-unifier` 3.0.0, and `api-diff` 5.0.0 are majors because of the name references

### Install

- The Helm chart `qubership-apihub` 2.16.0 is in the registry, with the product image tags pinned
- The agent image is 2.2.0, with Helm chart `qubership-apihub-agent` 2.2.0

### Fixes

- Adding a file to a package version accepts only allowed file types
- Promotion to Release rejects specifications with broken references
- The API Quality tab keeps the linter name visible on a narrow screen
- The Security Reports tab is highlighted when it is open
- The validation summary no longer reports a lint as running when no task is active
- Buttons no longer draw a black border on focus
