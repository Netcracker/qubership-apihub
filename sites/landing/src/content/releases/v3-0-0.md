## What's New in v3.0.0

OpenAPI operations and their diffs now render in api-doc-viewer. The package version list
can be sorted, Portal and Agents pages name the browser tab, and MCP search can target
groups you choose. The product Helm chart is published with the images.

### OpenAPI viewer

- An operation and its diff render in api-doc-viewer, in place of the legacy apispec-view
  operation viewers
- Circular schemas and oneOf branches render, including properties on a circular combiner
  branch
- A difference in api-kind shows in Doc View
- The Portal UI is 4.0.0 and api-doc-viewer is 5.0.0 because of this move
- api-diff 6.0.0, ddlapi 3.0.0, compatibility-suites 3.0.0, and apispec-view 3.0.0 moved
  with the same viewer change

### Versions and pages

- The version dropdown on a package can use a sorting strategy
- The backend sorts the package version list by first publication date
- Portal and Agents pages set the browser tab title from the page you are on

### MCP and the AI linter

- MCP search can look through a list of groups you pass under a workspace
- The get_api_operation_diff tool accepts a severity filter
- The AI linter splits issue deduplication into token-budgeted requests, so a long report
  stays inside the model context. api-linter-service 2.0.0 is a major because of that split

### Operations migration

- A partial operations migration can be limited to folder scopes

### Install

- The Helm chart `qubership-apihub` 3.0.0 is in the registry, with the product image tags
  pinned
- The agent image is 2.3.1, with Helm chart `qubership-apihub-agent` 2.3.1
- Portal backend 1.24.0, UI 4.0.0, build-task-consumer 3.6.1, api-linter-service 2.0.0,
  agents-backend 1.2.1, and java-task-consumer 0.2.0

### Fixes

- Clearing a package search restores the view mode you had before
- A quality-tab filter no longer stays applied when you switch documents
- The linter returns an error when APIHUB answers a non-200 for available roles, instead of
  panicking
- Tolerant publication works for a dashboard, including an invalid dashboard
- Response-tab icons on Compare versions no longer overlap
- A rendering loop that froze the page is fixed
