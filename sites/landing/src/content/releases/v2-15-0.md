## What's New in v2.15.0

A mid-size maintenance and platform release: search privacy, MCP/DDL tooling depth, status cleanup, and observability — with Agent held back for a connection-leak investigation.

### Search, MCP, and DDL
- Authorization on global search (results respect package access)
- MCP tools cover MCP and DDL contract entities
- MCP `api-packages-list` resource rework

### Catalog and lifecycle
- Package Version **Archived** status removed across Portal, backend, and workers
- Previous publish/migration UX: sort suspicious builds by affected count; "not migrated" counters
- Version and document labels with reserved keywords use predefined colors

### Quality and platform
- AI linter is optional (Spectral remains the default path)
- Go backend memory configuration updated (drop custom `SetGCPercent`)
- OpenTelemetry metrics and related Helm values
- Prometheus HTTP metrics re-enabled; scheduled build metrics job
- Agent UI integration tests on Kind; publish-version APM skill

### Fixes
- Deprecated-property change classification aligned across api-diff and api-processor
- API Changes "Tags" column no longer overlaps "Endpoint"
- Newly published versions appear in the version selector without a reload
- Global search of documents and packages respects API type
- Faster test-data cleanup on large databases
- DDL publish via the Portal dev proxy
